# This is my resume

To build this use Lualatex

### Building:
Install MiTex and install the [latex workshop extention](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop)

Install the latexmk package from mitex

Install strawberryperl

Download the Monserat font from [Google Fonts](https://fonts.google.com/specimen/Montserrat)

Set the setting.json to the one supplied in the repo
