# Building the resume in Zed

1. Install the **LaTeX** extension in Zed and run `brew install tectonic fonttools`.
2. Open this repository in Zed and edit `resume.tex`.
3. Open `resume-preview.png` in a split pane for an in-editor preview.
4. The file autosaves after one second and automatically rebuilds both the PDF and preview.

To build manually, open the command palette, choose **task: spawn**, and run **Build resume PDF**.
